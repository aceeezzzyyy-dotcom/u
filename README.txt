HOW TO PUT THIS ON GITHUB PAGES (so pics, video and music show up)

Upload EVERYTHING, keeping the folders exactly as they are:
  index.html, style.css, script.js
  images/   (about-you.jpg, photo1.jpg, photo2.jpg, photo3.jpg)
  videos/   (our-memory.mp4)
  music/    (our-song.mp3)

Tips:
- On github.com: Add file > Upload files, then drag the WHOLE FOLDERS (not just the files inside) so the folder names are kept.
- File names are case-sensitive on GitHub. Keep them lowercase exactly as above.
- Photos are .jpg now (they were real JPEGs named .png before).
- Settings > Pages > Deploy from a branch > main / (root). Wait 1-2 min, then hard-refresh (Ctrl+Shift+R).
- Music: browsers block autoplay, so tap the play button on the player.
